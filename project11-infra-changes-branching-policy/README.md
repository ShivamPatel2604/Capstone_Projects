# Project 11: Infra Changes with Branching Policy

## Goal
Follow a structured Git branching strategy for infrastructure changes.

## Branching Strategy
- Main branch: Stable production-ready code.
- Feature branch: Isolated infrastructure changes.
- Pull Request: Review changes before merging.

## Tasks Completed
- Created feature branch.
- Created infrastructure change documentation.
- Pushed feature branch to GitHub.
- Created Pull Request.
- Reviewed and merged Pull Request.

## Workflow
1. Create a feature branch.
2. Implement infrastructure changes.
3. Commit and push changes.
4. Open a Pull Request.
5. Review and merge into main.

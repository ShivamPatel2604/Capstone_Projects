# Project 2: Host a Static Website on Amazon S3 using Terraform

## Objective
Publish a static website using Amazon S3 and Terraform.

## AWS Services
- Amazon S3
- S3 Static Website Hosting
- S3 Bucket Policy

## Technologies
- AWS CLI
- Terraform
- HTML
- CSS
- Git and GitHub

## AWS Region
us-east-2 (Ohio)

## Project Structure

Project-2-S3-Static-Website/
├── terraform/
├── website/
├── evidence/
├── README.md
└── .gitignore

## Deployment Steps

1. Configure AWS authentication.
2. Initialize Terraform.
3. Validate Terraform configuration.
4. Create AWS infrastructure.
5. Enable S3 static website hosting.
6. Upload website files.
7. Access the public website endpoint.

## Expected Result

A publicly accessible static website hosted on Amazon S3
using Terraform Infrastructure as Code.

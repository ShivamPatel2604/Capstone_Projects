
# AWS Terraform Capstone Projects

A collection of AWS Cloud Infrastructure projects implemented using Terraform as part of my Cloud Engineering Capstone.

## Projects

### Project 1 - Linux EC2 Web Server
- Deploy Linux EC2 using Terraform
- Configure VPC and public subnet
- Configure Internet Gateway and routing
- Deploy Apache web server

Folder: `project1-linux-ec2-webserver/`

### Project 2 - S3 Static Website Hosting
- Create S3 bucket using Terraform
- Configure static website hosting
- Upload HTML and CSS files
- Configure bucket policies

Folder: `project2-s3-static-website/`

### Project 3 - EC2 State Monitoring with CloudWatch
- Deploy EC2 using Terraform
- Monitor CPU utilization
- Configure CloudWatch CPU alarm
- Generate CPU load and detect spikes

Folder: `project3-ec2-cloudwatch-monitoring/`

## Technologies Used
- Amazon Web Services (AWS)
- Terraform
- Amazon EC2
- Amazon S3
- Amazon CloudWatch
- Linux
- Git and GitHub

## AWS Region
Asia Pacific (Mumbai) - ap-south-1

## Repository Structure
Each project contains its own Terraform configuration, documentation and supporting files.

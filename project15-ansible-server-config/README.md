# Project 15: Automate Server Config with Ansible

## Objective
Use Ansible for remote configuration automation: set up an Ansible controller and install/configure a web server on remote Linux servers with a playbook, **without using SSH / port 22**.

## Setup
- Ansible controller: the Ubuntu 24.04 Linux VM used for previous projects
- Connection method: Ansible `amazon.aws.aws_ssm` connection plugin (AWS Systems Manager Session Manager over HTTPS 443)
- Managed nodes: 2 x Amazon Linux 2023 EC2 instances (`t3.micro`) provisioned by Terraform
- Region: ap-south-1 (Mumbai)
- Web server: Apache (`httpd`) installed and configured only by Ansible
- Security group: only HTTP (80) inbound, **no port 22**, no SSH key pair

## Architecture
```
Ubuntu VM (Ansible controller)
   |  HTTPS 443 (AWS APIs)                    S3 bucket (module file transfer)
   v                                                 ^
AWS Systems Manager  <--- outbound HTTPS --- SSM agent on each node
                                                     |
VPC 10.15.0.0/16 -> public subnet 10.15.1.0/24       |
   +-- shivam-project15-web-1 (Apache) <-------------+
   +-- shivam-project15-web-2 (Apache)  <-- HTTP 80 -- Internet
```

## Implementation Steps (run on the Linux VM)

### 1. Pull the latest code and verify AWS access
```bash
cd ~/aws-terraform-capstone
git pull
aws sts get-caller-identity
```

### 2. Set up the Ansible controller
Install Ansible, the AWS Python SDK, and the Session Manager plugin:
```bash
sudo apt update
sudo apt install -y ansible python3-boto3 python3-botocore
ansible-galaxy collection install 'amazon.aws:>=8.0.0,<10.0.0'

curl -fsSL "https://s3.amazonaws.com/session-manager-downloads/plugin/latest/ubuntu_64bit/session-manager-plugin.deb" -o /tmp/session-manager-plugin.deb
sudo dpkg -i /tmp/session-manager-plugin.deb

ansible --version
ansible-galaxy collection list amazon.aws
session-manager-plugin --version
```

### 3. Provision the managed nodes with Terraform
Terraform also generates the inventory (`ansible/inventory.ini`).
```bash
cd ~/aws-terraform-capstone/project15-ansible-server-config/terraform
terraform init
terraform fmt -check
terraform validate
terraform plan -out=tfplan
terraform apply tfplan
```

### 4. Confirm the nodes are registered with Systems Manager
Wait 2-3 minutes after apply, then:
```bash
aws ssm describe-instance-information --region ap-south-1 \
  --query "InstanceInformationList[].[InstanceId,PingStatus,PlatformName]" --output table
```
Both instances should show `Online`.

### 5. Prove port 22 is not used
```bash
aws ec2 describe-security-groups --region ap-south-1 \
  --filters Name=group-name,Values=shivam-project15-nodes-sg \
  --query "SecurityGroups[].IpPermissions[].[FromPort,ToPort]" --output table
```
Only port `80` is listed.

### 6. Verify controller -> node connectivity over SSM
```bash
cd ../ansible
cat inventory.ini
ansible webservers -m ping
```
Expected: `web1 | SUCCESS` and `web2 | SUCCESS` with `ping: pong`.

### 7. Confirm no web server exists yet
```bash
ansible webservers -m shell -a "rpm -q httpd || true"
```
Expected: `package httpd is not installed`.

### 8. Install the web server using the playbook
```bash
ansible-playbook webserver.yml --syntax-check
ansible-playbook webserver.yml
```
Expected: `PLAY RECAP` shows `failed=0` for both hosts, and the verify play returns HTTP 200 for each node.

### 9. Show idempotency (optional)
```bash
ansible-playbook webserver.yml
```
Expected: `changed=0` for both web servers.

### 10. Verify the web server
```bash
ansible webservers -m shell -a "systemctl is-active httpd"
terraform -chdir=../terraform output web_urls
```
Open both URLs in a browser; each page shows its own hostname and private IP.

## Troubleshooting
- `connection plugin 'amazon.aws.aws_ssm' was not found`: install the collection from step 2.
- URLs not opening: expected until the playbook has installed Apache.
- `ping` hangs / instance not in SSM: wait a few minutes; check `describe-instance-information` shows `Online`.
- `session-manager-plugin not found`: re-run the install in step 2.
- `Failed to import boto3`: `sudo apt install -y python3-boto3 python3-botocore`.
